# DevOps-Lab04 — DRILL OPS

DRILL OPS เป็นหน้าเว็บต้นแบบสำหรับวางแผนและฝึกซ้อมสถานการณ์จำลองของทีม IT Support และ Service Desk ช่วยให้ทีมได้ฝึกการสื่อสาร การประสานงาน และการแก้ไขปัญหาอย่างเป็นระบบก่อนเกิดเหตุการณ์จริง

## ความสามารถ

- แสดงสถานการณ์ฝึกซ้อมด้านเครือข่าย บัญชีผู้ใช้ และอุปกรณ์
- กรองรายการสถานการณ์ตามหมวดหมู่
- เปิดหน้าต่างเริ่มซ้อมเพื่อเลือกทีมและบทบาท
- แสดงตารางรอบฝึกซ้อม พร้อมปุ่มลงชื่อหรือยกเลิกการเข้าร่วม
- แสดงแนวทางการฝึกซ้อมตั้งแต่เลือกสถานการณ์จนถึงทบทวนผล
- รองรับหน้าจอขนาดต่าง ๆ และมีข้อความแจ้งผลการใช้งาน

## วิธีเปิดใช้งาน

โปรเจกต์นี้เป็นเว็บหน้าเดียว ไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์:

1. ดาวน์โหลดหรือ clone repository
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

## เทคโนโลยี

- HTML
- CSS
- JavaScript แบบ vanilla

## หมายเหตุ

นี่เป็นต้นแบบส่วนติดต่อผู้ใช้แบบ static การลงชื่อเข้าร่วม การเริ่มซ้อม และการเข้าสู่ระบบยังไม่เชื่อมต่อ backend และข้อมูลจะไม่ถูกบันทึกถาวร ฟอนต์และภาพพื้นหลังโหลดจากบริการภายนอก จึงอาจแสดงผลต่างออกไปเมื่อไม่มีอินเทอร์เน็ต
